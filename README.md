# Zadanie2AkwizycjaDanych

## Instalacja

Uruchom środowisko venv.
Następnie zainstaluj wymagane biblioteki znajdujące się w pliku `requirements.txt`:

```bash
pip install -r requirements.txt
```

## Uruchamianie

### 1. Crawler

```bash
python crawler.py
```

### 2. Indeksowanie stron

Aby uruchomić proces indeksowania, wykonaj poniższe polecenie w terminalu:

```bash
python Indekser.py
```

### 2. Wyszukiwanie

Aby wyszukać tekst lub słowa kluczowe, przekaż je bezpośrednio po nazwie skryptu:

```bash
python Wyszukiwarka.py wyszukiwany tekst
```
